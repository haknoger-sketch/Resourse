# Resourse

Ресурспак сервера SquareSMP. Файл один: pack.zip.

Раздаётся игрокам напрямую по ссылке на конкретный коммит — так адрес всегда
указывает ровно на те байты, для которых посчитан хеш в server.properties.
Обновляется скриптом D:/SquareNetwork/publish_pack.py, вручную сюда ничего
класть не нужно.
